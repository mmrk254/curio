CURIO VERSION 1.0 - HOW TO RUN

Project folders

frontend
  Next.js + TypeScript user interface.

backend
  Spring Boot API connected to PostgreSQL.

Database

PostgreSQL is expected on:
  host: 127.0.0.1
  port: 5432
  database: curio
  username: postgres
  password: postgres

The backend uses Flyway migrations.
Tables are created automatically when the backend starts.

Backend commands

1. Open PowerShell.

2. Go to the backend folder:
   cd C:\Users\Mark\Desktop\CURIO\backend

3. Start the backend:
   $env:CURIO_DB_PASSWORD='1271'
   .\mvnw.cmd spring-boot:run

4. Backend URL:
   http://127.0.0.1:8080

5. Swagger docs:
   http://127.0.0.1:8080/swagger-ui.html

Frontend commands

1. Open another PowerShell.

2. Go to the frontend folder:
   cd C:\Users\Mark\Desktop\CURIO\frontend

3. Install packages if needed:
   npm install

4. Start the frontend:
   npm run dev -- --hostname 127.0.0.1 --port 3001

5. Open:
   http://127.0.0.1:3001/register

Testing flow

1. Start PostgreSQL.
2. Start the backend.
3. Start the frontend.
4. Register a school.
5. Login with the same email/password.
6. On the dashboard, use Add Real Records to create:
   - Class
   - Parent
   - Student
   - Invoice
   - Payment
   - Attendance
   - Application
   - Notice

Important testing note

Some fields need IDs, such as classId, parentId, studentId, and invoiceId.
The dashboard shows reference records on the right.
Click a reference record to copy its ID.
